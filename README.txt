ROH FIT - pacote para publicação na Vercel

Arquivos:
- index.html: aplicação web principal
- manifest.webmanifest: configuração PWA
- sw.js: service worker
- icons/: ícones PWA

Para publicar:
1. Extraia o ZIP.
2. Envie o conteúdo da pasta para o projeto da Vercel.
3. Confirme que index.html está na raiz do projeto.
